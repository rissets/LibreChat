Bantuan BP Batam AI

Gunakan ruang kerja ini untuk percakapan, analisis dokumen, agent, kode, suara, dan gambar. Hasil AI perlu diperiksa sebelum digunakan untuk keputusan.

Mulai menggunakan ruang kerja

  1. Buka BP Batam AI, lalu masuk menggunakan akun lokal.
  2. Pilih model pada bagian atas percakapan. Gunakan agent untuk pekerjaan yang memerlukan tool.
  3. Lampirkan dokumen untuk pencarian dan analisis berbasis sumber. Periksa kutipan serta file yang digunakan.

Pertanyaan umum

Bagaimana membuat atau mengedit gambar?

Pilih Asisten BP Batam, lalu jelaskan gambar yang diinginkan. Untuk edit, lampirkan atau rujuk satu gambar dan jelaskan perubahan. Provider default mendukung satu gambar masukan.

Bagaimana menggunakan suara?

Buka pengaturan Speech pada akun. Gunakan engine External dan voice default atau F1. Tombol mikrofon mentranskripsi rekaman; Read Aloud membacakan jawaban. Izinkan mikrofon pada browser.

Apa yang terjadi jika provider gagal?

Konfigurasi multimedia kustom akan mencoba default Hellodigi. Jika layanan gambar default gagal, pesan error ditampilkan. TTS dapat memakai suara browser. Untuk transkripsi browser, rekam ulang setelah kegagalan.

Bagaimana menjalankan kode dan artifact?

Pilih agent dengan Code Interpreter untuk Python, JavaScript, dan runtime yang tersedia. Artifact membuka preview interaktif pada panel percakapan. Jangan menjalankan kode yang tidak dipahami atau memasukkan rahasia ke dalam artifact.

Mengapa dokumen tidak ditemukan?

Pastikan unggahan selesai, file terpilih di percakapan, dan agent memiliki File Search. Administrator dapat memeriksa layanan indeks dokumen dan status provider.

Untuk administrator

Kelola akun dan konfigurasi melalui Administrasi BP Batam AI. Atur endpoint, model, suara, dan gambar melalui Multimedia BP Batam AI. Perubahan provider berlaku pada permintaan berikutnya.

Gunakan ./stack status di folder instalasi untuk memeriksa layanan. Jangan membagikan API key, kata sandi, atau log yang berisi data sensitif.
